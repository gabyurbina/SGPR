# Plan de Lanzamiento / Release Plan - SGPR

## Objetivo
Planificar la liberación de la plataforma a producción con verificaciones y criterios de aceptación.

## Hitos
- Hito 1 (Beta interna): 15/05/2026 — funcionalidades principales implementadas y pruebas internas.
- Hito 2 (RC - Release Candidate): 10/06/2026 — correcciones y pruebas completas.
- Hito final (Producción): 30/06/2026 — despliegue a servidor de producción.

## Criterios de aceptación
- Todas las pruebas unitarias e integradas pasan.
- Backups y plan de restauración verificados.
- Documentación entregada y manuales disponibles.

## Rollout
1. Deploy en entorno staging.
2. Tests de humo automáticos y manuales.
3. Plan de rollback preparado.
