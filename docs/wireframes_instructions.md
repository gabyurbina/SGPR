# Instrucciones para Wireframes y Mockups

Para completar los wireframes:
- Crear imágenes PNG o SVG por cada pantalla: login, lista trabajadores, formulario solicitud, estadisticas, detalle solicitud.
- Nombrar archivos: `login.png`, `lista_trabajadores.png`, `form_solicitud.png`, `estadisticas.png`, `detalle_solicitud.png` y subir a `/docs/wireframes/`.
- Incluir breve descripción del comportamiento interactivo en un archivo `wireframes_notes.md`.
