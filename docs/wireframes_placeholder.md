# Wireframes y Mockups - SGPR

Este archivo contiene descripciones de wireframes y rutas donde colocar los archivos gráficos.

Páginas principales y descripción breve:
- Login: campos usuario/contraseña, enlace "olvidé mi contraseña".
- Lista Trabajadores: tabla con búsqueda y botones (Ver, Reporte, Editar).
- Formulario Solicitud: campos tipo, fecha inicio/fin, motivo, adjunto.
- Panel Estadísticas: filtros, gráficos (canvas), botones exportar.
- Detalle Solicitud: historial y acciones (Aprobar/Rechazar).

Archivos recomendados:
- `/docs/wireframes/login.png`
- `/docs/wireframes/lista_trabajadores.png`
- `/docs/wireframes/form_solicitud.png`
- `/docs/wireframes/estadisticas.png`

(Colocar imágenes en la carpeta `docs/wireframes/` para integrarlas en la documentación).
