# Instrucciones para Empaquetado Final y Entrega

1. Verificar que `git` repo esté limpio y con tag de versión.
2. Incluir carpeta `/docs/` con todos los manuales y evidencia.
3. Comprimir en ZIP: `zip -r SGPR_release_v1.0.zip .` (excluyendo entornos virtuales)
4. Subir al repositorio de entrega o compartir por SFTP según política del cliente.
