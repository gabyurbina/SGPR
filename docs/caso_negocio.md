# Caso de Negocio - SGPR

## Resumen ejecutivo
El sistema SGPR centraliza la gestión de permisos y reposos, reduciendo tiempo administrativo, errores y mejorando trazabilidad. Se espera retorno en productividad y cumplimiento normativo.

## Problema
Procesos manuales dispersos; falta de trazabilidad y dificultad para generar reportes consolidados.

## Beneficios
- Reducción de tiempo en gestión de solicitudes
- Informes y auditoría confiables
- Toma de decisiones basada en datos

## Costos y recursos
Desarrollo realizado por una persona; costos asociados: infraestructura, pruebas y mantenimiento. Se recomienda asignar recursos de soporte.

## Riesgos
- Dependencia de un único desarrollador
- Limitaciones de compatibilidad de navegadores para exportes (canvas tainted)

## Conclusión
Proyecto viable y con impacto operativo positivo; recomendable puesta en producción tras pruebas de integración y plan de respaldo.
